Project Name: YT-CUT

Description: YT-CUT is an platform, where users can put the link of youtube video or live streams of their choice, to cut (trim) and get that trimmed video downloaded in highest quality.

You are senior software engineer, you are going to create this app. Before, heading towards implementation. I want a PRD for this particular app.

In this YT-CUT app,
- No signup
- No account management
- User put the link of a video or live stream
- User can drag to the timestamps and cut
- User should be able to download the file instantly

These are few common instruction, so that you get some idea about the app.
